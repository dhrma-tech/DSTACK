# Skills

Phase 1 ships fourteen manifest-driven skills:

`/office-hours`, `/autoplan`, `/plan-ceo-review`, `/plan-eng-review`, `/design-consultation`, `/design-review`, `/review`, `/qa`, `/qa-only`, `/investigate`, `/ship`, `/context-save`, `/context-restore`, and `/browse`.

Each skill has a YAML manifest, a prompt template, an output schema contract, allowed tools, prerequisite artifacts, and a thin handler.
